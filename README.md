🚗 Auto Fácil — Sistema de Vendas de Veículos

📌 Sobre o projeto

O Auto Fácil é um projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas (ADS). Seu objetivo é organizar informações sobre clientes, vendedores, veículos e vendas por meio de um banco de dados relacional.

🛠️ Tecnologias utilizadas

* SQL
* Banco de dados relacional
* Comandos CREATE TABLE, INSERT e SELECT
* Relacionamentos entre tabelas
* Consultas com INNER JOIN

⚙️ Funcionalidades

* Cadastro de clientes.
* Cadastro de vendedores.
* Cadastro de veículos.
* Registro de vendas.
* Consulta de vendas e relacionamentos entre tabelas.

▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo auto-facil.sql em um sistema gerenciador de banco de dados compatível.
3. Execute os comandos SQL.
4. Consulte os dados utilizando as instruções SELECT.
